Pembuat Undangan PDF

Tempelkan nama & alamat tamu ke desain undangan Anda. File Anda diproses di browser — tidak ada yang dikirim ke server.

1 Pilih file PDF desain

File desain undangan Anda (dari Word, Canva, atau Inkscape, diekspor sebagai PDF).

2 Pilih file CSV daftar tamu

Dua kolom: nama dan alamat. Dari Excel, pilih "Simpan sebagai" → CSV UTF-8.

3 Pilih file font

Font .ttf untuk nama dan alamat. Font ini akan tertanam di dalam PDF hasil, jadi penerima undangan tidak perlu punya font yang sama.

4 Atur posisi tulisan

Klik-tarik di atas kertas untuk membuat kotak di tempat teks akan muncul. Kotak ini tidak akan tercetak — hanya teksnya.

Belum ada kotak. Klik-tarik di atas kertas untuk membuat kotak pertama.

5 Buat dan unduh

Semua PDF dikirim ke folder Downloads komputer Anda sebagai satu file ZIP.
